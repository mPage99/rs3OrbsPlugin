# RuneLite XP Orb Plugin

This context names the XP and skill-progress indicators shown by the RuneLite plugin.

## Language

**XP orb**:
A skill-specific indicator that pairs the skill's icon with a ring showing progress through its current level.
_Avoid_: progress indicator

**XP drop**:
A temporary display of XP gained for a skill, paired with that skill's icon.
_Avoid_: XP popup
